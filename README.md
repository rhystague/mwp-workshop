# Guardrails Index

This directory contains operating instructions and reusable materials for research-assistant work in this vault.

Start here:
- `AGENTS.md`: standing instructions for future assistants.
- `../Researcher Identity.md`: concise research identity and positioning.
- `../Research Questions.md`: living list of possible research questions to consult when developing papers, processing notes, or refining directions.
- `workflows/Paper Processing Workflow.md`: practical workflow for processing papers into notes and maps.
- `templates/Paper Note Template.md`: default paper-note structure.
- `templates/Map Note Template.md`: default synthesis-note structure.
- `templates/Potential Paper Template.md`: default paper-idea structure.
- `prompts/Process a Paper.md`: prompt to use when sharing a paper for processing.
- `prompts/Develop a Paper Idea.md`: prompt for turning an idea into a possible paper.
- `checklists/Weekly Research Rhythm.md`: lightweight weekly review checklist.

The aim is to keep the vault useful for writing and research judgement, not to create a heavy knowledge-management system.
